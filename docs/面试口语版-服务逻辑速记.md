# 面试口语版：各服务逻辑速记（精简版）

> 目的：给面试官用的“口语化解释”，只讲核心链路。

---

## 项目总览（面试可直接口述）

这是一个实时对战交互平台的后端项目，定位是“多人在线 + 实时对局 + 聊天 + 会话治理”的一体化能力。整体拆成四个服务：Gateway 统一入口做鉴权和路由；Game Service 负责房间和对局（建房、入房、准备、落子、认输、重开）；Chat Service 负责大厅/房间/私聊消息与通知推送；System Service 负责用户、好友、通知和文件存储，并与 Keycloak 对接认证。核心流程是：用户登录拿 JWT → 网关鉴权 → 进入大厅建房/入房 → WebSocket 建连进行对局实时落子 → 状态落 Redis 并广播快照 → 断线可恢复；聊天和通知在对局中实时推送并支持持久化。项目以 roomId 做房间隔离，状态机 + Redis CAS 保证并发一致性，会话失效事件通过 Kafka 解耦广播，整体可扩展到更多小游戏场景。

---

## 项目亮点与实现逻辑（口语版）

### 第一梯队（面试官能听懂的业务亮点）

1) **多人同局不乱（落子不冲突）**
- 同一回合只允许一个人落子成功，其他并发会被拒绝。
- 落子时服务端带“期望步数 + 期望轮到方”做原子校验，保证不会双写。

2) **断线/刷新后能回到原局**
- 不是重新开局，而是恢复到原来的棋盘、回合、计时。
- 通过 `seatKey + FullSync` 快照把座位和状态一起恢复。

3) **回合倒计时可靠**
- 计时在服务端管理，状态落 Redis。
- 服务重启后还能恢复 deadline，不会把输赢判错。

4) **单设备登录与踢线**
- 新设备登录后旧设备会被踢下线，旧连接不能继续操作。
- 会话状态由 Redis 统一管理，网关和服务端双重校验。

### 第二梯队（有价值但要讲细一点）

5) **房间不串**
- WS 主题、Redis 键、操作校验都绑定 `roomId`。
- 服务端按 userId 校验是否是该房间成员/座位，seatKey 只做恢复，不做授权。

6) **聊天消息可靠**
- 聊天实时推送，同时落库（Redis 缓存 + PostgreSQL 持久化）。
- 私聊用 clientOpId 幂等，避免重复入库。

## 1) Gateway（网关）

一句话：**统一入口 + 鉴权 + 路由 + WS 透传 + 限流**。

- 所有 HTTP/WS 请求先过网关校验 JWT。
- 合法请求再转发到 game/chat/system 服务。
- WebSocket 做握手鉴权和 token 透传，避免匿名连接。
- 维护 token 黑名单与会话失效校验，支持踢线。

你可以说：
> “网关就是统一门禁，先验身份，再转发，WS 也在这里做鉴权。”

---

## 2) Game Service（游戏对局）

一句话：**房间 + 对局状态机 + 实时落子 + 重连恢复**。

- 玩家建房、入房、准备、开始游戏。
- 对局中落子走 WS，服务端做回合校验和并发 CAS 写。
- 状态快照落 Redis，断线重连靠快照恢复。
- PVE 模式会调 AI，落子也走同一套校验。

你可以说：
> “游戏服务就是管房间和对局，核心是状态机+CAS，保证同回合只成功一次，掉线还能恢复。”

---

## 3) Chat Service（聊天与通知）

一句话：**大厅/房间/私聊消息 + 消息持久化 + WS 推送**。

- 大厅和房间聊天走 WS 广播。
- 私聊先校验好友关系，再写库并点对点推送。
- 历史消息存 PostgreSQL，Redis 做缓存。

你可以说：
> “聊天服务做实时推送+持久化，房间广播，私聊点对点，消息不丢。”

---

## 4) System Service（用户与社交）

一句话：**用户/好友/通知/头像 + Keycloak 对接**。

- 用户注册登录走 Keycloak，系统服务同步本地用户资料。
- 提供用户资料、好友申请、通知管理等接口。
- 头像/文件存 MinIO。

你可以说：
> “系统服务就是用户域，Keycloak 负责认证，系统服务负责资料、好友和通知。”

---

## 5) 公共库（libs）

一句话：**会话治理 + 事件广播 + 通用工具**。

- `session-common`：统一登录会话/WS 会话注册表。
- `session-kafka-notifier`：会话失效事件发布与消费。
- `web-common`：统一 API 返回、JWT 用户解析、Feign 鉴权透传。

你可以说：
> “公共库主要是会话治理和跨服务复用，避免每个服务重复造轮子。”
